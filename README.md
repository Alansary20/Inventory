# جرد · مخزون · أسعار (نسخة الويب)

موقع ثابت (PWA) يعمل بالكامل داخل المتصفح، والبيانات تُحفظ في متصفحك فقط.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub (مثلاً `jard`).
2. ارفع كل محتويات هذا المجلد (index.html و js و vendor و icons ...) إلى الفرع `main`.
3. من Settings ← Pages ← Source: Deploy from a branch ← main / (root) ← Save.
4. افتح الرابط `https://USERNAME.github.io/jard/` (HTTPS مطلوب للكاميرا).
5. في Chrome على أندرويد: القائمة ← «تثبيت التطبيق».

## ملاحظات
- النسخ الاحتياطي والاستعادة من زر ☰ (البيانات تُمسح إذا مسحت بيانات المتصفح).
- قراءة الباركود: Chrome أندرويد يستخدم قارئ المتصفح، وسفاري/iOS وغيره يستخدم zxing-cpp (WebAssembly) وهو أقوى مكتبة مجانية.
- التصدير إلى Excel بنفس ألوان التطبيق (على iOS يفتح مشاركة الملف: «حفظ في الملفات»).
